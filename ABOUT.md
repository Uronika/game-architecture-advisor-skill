# About

Game Architecture Advisor is a portable skill for making evidence-led game architecture and system-design decisions. It supports Unity/C#, Tuanjie, and cross-engine or Web game work.

The skill combines local lexical retrieval with optional Ollama-based semantic reranking, then guides the agent through adaptive clarification, option comparison, and explicit user approval before implementation. It is designed for Codex and Claude Code installations that need a common decision protocol without a shared proprietary service.

This repository distributes only original instructions, scripts, tests, and documentation. Third-party books and engine documentation are intentionally obtained and indexed locally by each user.
